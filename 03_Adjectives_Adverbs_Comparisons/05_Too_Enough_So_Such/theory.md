# Cấu trúc Too...to, Enough...to, So...that, Such...that (A2–B2)

## 1. Tổng quan bản chất

Bộ bốn cấu trúc **Too...to**, **Enough...to**, **So...that**, và **Such...that** đều xoay quanh một trục tư duy cốt lõi: **diễn đạt MỨC ĐỘ (Degree) và KẾT QUẢ / KHẢ NĂNG (Result / Capability)**.

Hãy hình dung một **ngưỡng đạt chuẩn (the threshold)** giống như mực nước cần thiết để con thuyền có thể nổi:

- **`too ... to`**: **Vượt quá ngưỡng cho phép** → Quá nhiều / quá mức đến nỗi **KHÔNG THỂ** làm gì. Bản thân `too` đã mang **nghĩa phủ định ngầm** (không cần thêm `not` ở vế `to V`).
- **`enough ... to`**: **Đạt đúng ngưỡng tối thiểu** → **ĐỦ** điều kiện để làm gì (nếu thêm `not` ở phía trước thành `not ... enough to`, nghĩa là **CHƯA ĐỦ** để làm gì).
- **`so ... that`** & **`such ... that`**: **Mức độ cao đến mức dẫn tới một hệ quả cụ thể** → *Quá ... đến nỗi mà ...*. Khác với `too...to` (chỉ kết nối bằng động từ nguyên mẫu `to V`), `so...that` và `such...that` mở ra hẳn một **mệnh đề kết quả (`S + V`)**, linh hoạt diễn đạt cả kết quả **khẳng định** lẫn **phủ định**.

> 💡 **Tóm tắt trực quan trong 1 dòng:**
> - `too + adj/adv + to V` = Vượt ngưỡng → **Không làm được** (tiêu cực).
> - `adj/adv + enough + to V` = Đạt ngưỡng → **Làm được** (tích cực).
> - `so + adj/adv + that + S + V` / `such + (a/an) + adj + N + that + S + V` = Mức độ mạnh → **Gây ra hệ quả gì**.

## 2. Công thức & Cấu trúc chi tiết

### 2.1. Cấu trúc với `TOO ... TO` (Quá ... để làm gì / Quá ... đến nỗi không thể ...)

| Dạng câu | Công thức chuẩn | Ví dụ minh họa |
| :--- | :--- | :--- |
| **Khẳng định** | `S + be / V + too + adj / adv + (for sb) + to V` | The **deadline** is **too tight for us to finish** the report tonight. |
| **Phủ định** | `S + be not / trợ ĐT + not + V + too + adj / adv + (for sb) + to V` | This system isn't **too sophisticated for beginners to learn**. *(Không quá phức tạp đến mức người mới không học được)* |
| **Nghi vấn (Yes/No)** | `Be / Trợ ĐT + S + (V) + too + adj / adv + (for sb) + to V?` | Is the **budget** **too tight for the team to hire** another designer? |
| **Nghi vấn (Wh-)** | `Wh- + be / trợ ĐT + S + (V) + too + adj / adv + (for sb) + to V?` | Why is this issue **too sensitive for the manager to discuss** publicly? |
| **Nâng cao (B2)** | `too + adj + a/an + N (đếm được số ít) + to V` | It is **too crucial a decision to make** without **sufficient** data. |

---

### 2.2. Cấu trúc với `ENOUGH ... TO` (Đủ ... để làm gì)

Điểm sống còn của `enough` là **vị trí đứng khác nhau giữa Tính/Trạng từ và Danh từ**:

- **Sau Tính từ / Trạng từ**: `adj / adv + enough`
- **Trước Danh từ**: `enough + N` (đếm được số nhiều hoặc không đếm được)

| Dạng câu | Công thức chuẩn | Ví dụ minh họa |
| :--- | :--- | :--- |
| **Khẳng định (Adj/Adv)** | `S + be / V + adj / adv + enough + (for sb) + to V` | She is **qualified enough to lead** the international department. |
| **Khẳng định (Noun)** | `S + V + enough + N + (for sb) + to V` | We have **enough reliable data for the analysts to draw** a conclusion. |
| **Phủ định (Adj/Adv)** | `S + be not / trợ ĐT + not + V + adj / adv + enough + (for sb) + to V` | He didn't work **efficiently enough to meet** the **deadline**. |
| **Phủ định (Noun)** | `S + trợ ĐT + not + V + enough + N + (for sb) + to V` | The firm doesn't have **enough budget to negotiate** a bigger office. |
| **Nghi vấn (Yes/No)** | `Be / Trợ ĐT + S + (V) + adj/adv + enough / enough + N + (for sb) + to V?` | Are these laptops **affordable enough for students to buy**? |
| **Nghi vấn (Wh-)** | `Wh- + be / trợ ĐT + S + (V) + adj/adv + enough / enough + N + to V?` | How much time is **long enough to prepare** a **persuasive** pitch? |

---

### 2.3. Cấu trúc với `SO ... THAT` (Quá ... đến nỗi mà ...)

`So` là trạng từ, chỉ đi trực tiếp với **tính từ**, **trạng từ**, hoặc **4 lượng từ đặc biệt (`many`, `much`, `few`, `little`)**.

| Dạng câu | Công thức chuẩn | Ví dụ minh họa |
| :--- | :--- | :--- |
| **Cơ bản (Adj/Adv)** | `S + be / V + so + adj / adv + that + S + V` | The **commute** was **so exhausting that** I felt completely **exhausted** by 6 p.m. |
| **Với N đếm được số nhiều** | `S + V + so + many / few + N (số nhiều) + that + S + V` | There were **so many overwhelming tasks that** we had to **postpone** the meeting. |
| **Với N không đếm được** | `S + V + so + much / little + N (không đếm được) + that + S + V` | We had **so little sufficient time that** we couldn't **concentrate** properly. |
| **Nâng cao (B2)** | `S + be / V + so + adj + a/an + N (số ít) + that + S + V` | He gave **so persuasive a speech that** even **reluctant** voters supported him. |
| **Phủ định / Nghi vấn** | `S + be not / trợ ĐT not + V + so + ...` / `Be / Trợ ĐT + S + so + ...?` | Was the storm **so tremendous that** flights were cancelled? |

---

### 2.4. Cấu trúc với `SUCH ... THAT` (Quá ... đến nỗi mà ...)

`Such` là từ hạn định, luôn đi với **cụm danh từ**. Phải chia theo **3 loại danh từ**:

| Loại danh từ | Công thức chuẩn | Ví dụ minh họa |
| :--- | :--- | :--- |
| **N đếm được số ít** | `S + V + such + a/an + (adj) + N (số ít) + that + S + V` | It was **such a tight schedule that** nobody took a lunch break. |
| **N đếm được số nhiều** | `S + V + such + (adj) + N (số nhiều) + that + S + V` | They are **such reliable partners that** we never **hesitate** to work with them. |
| **N không đếm được** | `S + V + such + (adj) + N (không đếm được) + that + S + V` | The server suffered **such severe damage that** user data became **vulnerable**. |
| **Với `a lot of`** | `S + V + such + a lot of + N + that + S + V` | She made **such a lot of progress that** her mentor praised her. |
| **Phủ định / Nghi vấn** | `S + không dùng 'not' ở such; phủ định đặt ở V hoặc mệnh đề that` / `Is it such a...?` | Isn't it **such a crucial opportunity that** we shouldn't miss it? |

---

### 2.5. Đảo ngữ sơ lược với `SO` và `SUCH` (Trình độ B2)

Khi muốn **nhấn mạnh mức độ vượt trội** trong văn viết trang trọng (báo chí, IELTS Writing, thuyết trình), ta đưa `So` hoặc `Such` lên đầu câu và **đảo trợ động từ / `be` lên trước chủ ngữ**:

- **Đảo ngữ với `SO`**:
  `So + adj / adv + be / trợ động từ + S + (V) + that + S + V`
  - *So **tight** was the **deadline** that the engineers worked overnight.*
  - *So **efficiently** did she manage the project that costs dropped by 20%.*
- **Đảo ngữ với `SUCH`**:
  `Such + be + (the) + (adj) + N + that + S + V` *(hoặc `Such + a/an + adj + N + be + S + that...`)*
  - *Such was the **tremendous** impact of the policy that every company adapted quickly.*

### Bảng tóm tắt tra cứu nhanh

| Cấu trúc | Từ loại đi kèm ngay sau | Mệnh đề/Cụm theo sau | Sắc thái nghĩa |
| :--- | :--- | :--- | :--- |
| `too` | `adj / adv` *(hoặc `adj + a/an + N`)* | `(for sb) + to V` | Quá mức → **Không thể** |
| `enough` | Đứng **sau** `adj/adv`; đứng **trước** `N` | `(for sb) + to V` | Đủ ngưỡng → **Có thể** *(hoặc `not...enough` = chưa đủ)* |
| `so` | `adj / adv / many / few / much / little` | `that + S + V` | Quá ... → **Dẫn tới hệ quả** |
| `such` | `(a/an) + (adj) + N` / `a lot of + N` | `that + S + V` | Quá ... → **Dẫn tới hệ quả** |

## 3. Cách dùng chi tiết (kèm Ví dụ song ngữ EN–VI)

### Cách dùng 1: Diễn đạt giới hạn vượt mức khiến hành động không thực hiện được (`too ... to`)
Dùng khi mức độ của tính chất vượt quá khả năng xử lý của chủ thể, dẫn đến không thể làm hành động ở `to V`. Khi chủ ngữ của câu không phải người thực hiện hành động `to V`, ta chèn **`for + tân ngữ`** trước `to V`.
- This **sophisticated** software is **too complex for new interns to master** in one day.
  *(Phần mềm tinh vi này quá phức tạp để các thực tập sinh mới có thể thành thạo trong một ngày.)*
- The noise outside was **too distracting for me to concentrate** on my thesis.
  *(Tiếng ồn bên ngoài quá gây xao nhãng đến nỗi tôi không thể tập trung vào luận văn.)*

### Cách dùng 2: Diễn đạt điều kiện tối thiểu để thực hiện hành động (`enough ... to`)
Dùng để khẳng định ai đó/cái gì đó **đạt chuẩn** (hoặc ở thể phủ định là **chưa đạt chuẩn**) để làm việc gì. Có thể lược bỏ `to V` nếu ngữ cảnh đã rõ, hoặc thêm `for sb` để chỉ rõ đối tượng thực hiện.
- Is the **budget** **large enough for the committee to approve** the renovation?
  *(Ngân sách có đủ lớn để ủy ban phê duyệt việc cải tạo không?)*
- We have **sufficient** experience and **enough resources to negotiate** better terms.
  *(Chúng tôi có kinh nghiệm đầy đủ và đủ nguồn lực để đàm phán các điều khoản tốt hơn.)*
- He didn't speak **persuasively enough to convince** the **reluctant** board members.
  *(Anh ấy đã không nói đủ thuyết phục để làm các thành viên hội đồng quản trị còn ngần ngại tin tưởng.)*

### Cách dùng 3: Nhấn mạnh mức độ tính chất/hành động dẫn đến hệ quả (`so ... that`)
Dùng khi muốn nêu rõ **nguyên nhân (mức độ)** ở mệnh đề chính và **kết quả cụ thể** (có thể tốt hoặc xấu) ở mệnh đề `that`. Trong văn nói thân mật, `that` đôi khi được lược bỏ.
- The **consequence** of the delay was **so severe that** the firm lost two major clients.
  *(Hậu quả của sự chậm trễ nghiêm trọng đến mức công ty đã mất hai khách hàng lớn.)*
- The team worked **so efficiently that** they finished three days ahead of the **deadline**.
  *(Nhóm làm việc hiệu quả đến nỗi họ hoàn thành sớm hơn hạn chót ba ngày.)*

### Cách dùng 4: Nhấn mạnh số lượng lớn hoặc cực ít dẫn đến hệ quả (`so many/much/few/little ... that`)
Khi muốn nhấn mạnh **số lượng** của danh từ gây ra kết quả gì, ta bắt buộc phải dùng `so` kết hợp với các lượng từ `many, few, much, little` (tuyệt đối không dùng `such`).
- There are **so many affordable** options on the market **that** consumers often **hesitate** before choosing.
  *(Có quá nhiều lựa chọn giá cả phải chăng trên thị trường đến nỗi người tiêu dùng thường do dự trước khi chọn.)*
- The old server had **so little** protection **that** customer records were **vulnerable** to attacks.
  *(Máy chủ cũ có quá ít lớp bảo vệ đến mức dữ liệu khách hàng rất dễ bị tấn công.)*

### Cách dùng 5: Nhấn mạnh đặc điểm của một sự vật/sự việc (Cụm danh từ) dẫn đến hệ quả (`such ... that`)
Khi trọng tâm nhấn mạnh là một **danh từ hoặc cụm danh từ** (ví dụ: một cơn bão, một người bạn, một lượng công việc), ta dùng `such ... that` và chia đúng `a/an` theo danh từ chính.
- It was **such an overwhelming workload that** several staff members felt **exhausted**.
  *(Đó là một khối lượng công việc choáng ngợp đến nỗi nhiều nhân viên cảm thấy kiệt sức.)*
- They offered **such reliable** customer service **that** nobody wanted to switch providers.
  *(Họ cung cấp dịch vụ khách hàng đáng tin cậy đến mức không ai muốn đổi nhà cung cấp.)*

### Cách dùng 6: Nhấn mạnh tu từ ở trình độ B2 (Đảo ngữ với `So / Such` & cấu trúc `too/so + adj + a/an + N`)
Dùng trong văn phong học thuật, báo cáo hoặc bài luận để tạo ấn tượng mạnh về mặt ngữ pháp.
- **So crucial was** the timing **that** any further delay could ruin the deal.
  *(Thời điểm đó tối quan trọng đến mức bất kỳ sự trì hoãn nào thêm đều có thể làm hỏng thỏa thuận.)*
- **Such was** her **tremendous** dedication **that** she was promoted within six months.
  *(Sự cống hiến to lớn của cô ấy mạnh mẽ đến nỗi cô ấy được thăng chức chỉ trong vòng sáu tháng.)*

## 4. Dấu hiệu nhận biết, Ngoại lệ & Bẫy đề thi

### 4.1. Dấu hiệu nhận biết nhanh (kèm cảnh báo)
- Thấy **`that + S + V`** ở phía sau → Xét ngay **`so ... that`** hoặc **`such ... that`** (loại `too` và `enough`).
- Thấy **`(for sb) + to V`** ở phía sau → Xét **`too ... to`** hoặc **`enough ... to`** (loại `so` và `such`).
- Thấy **`many / much / few / little`** đứng trước danh từ → Bắt buộc dùng **`so`**, không dùng `such`.
- ⚠️ **Cảnh báo không dùng máy móc**: Không phải cứ thấy `to V` là chọn `too`! Phải đọc **ngữ nghĩa tích cực hay tiêu cực**:
  - *"Món súp đủ nguội để ăn"* → **cool enough to eat** (tích cực/làm được).
  - *"Món súp quá nóng để ăn"* → **too hot to eat** (tiêu cực/không làm được).

### 4.2. Ngoại lệ đáng chú ý
1. **`too` mang nghĩa tích cực (Ngoại lệ giao tiếp/thành ngữ)**:
   - `only too happy / glad / pleased to V` = rất sẵn lòng làm gì (*I am **only too happy to** help you*).
   - `can't / couldn't ... too ...` = làm bao nhiêu cũng không đủ (*You **can't be too careful** with online passwords* = Cẩn thận bao nhiêu cũng không thừa).
   - `too good to be true` = quá tốt đẹp đến khó tin.
2. **Vị trí trang trọng của `enough` với danh từ**: Trong văn chương cổ hoặc trang trọng, đôi khi thấy `time enough`, nhưng trong **mọi bài thi chuẩn hóa (THPT, TOEIC, IELTS)**, hãy luôn đặt **`enough` TRƯỚC danh từ** (`enough time`).

### 4.3. Các bẫy đề thi kinh điển
1. **Bẫy 1 — Thừa tân ngữ (`it / them / him / her`) sau `to V`**:
   - ❌ *The suitcase is too heavy for me to lift **it**.*
   - ✅ *The suitcase is too heavy for me to lift.* (Vì `the suitcase` đã làm chủ ngữ của câu rồi).
2. **Bẫy 2 — Đặt sai vị trí `enough`**:
   - ❌ *He isn't **enough qualified** to apply.* → ✅ *He isn't **qualified enough** to apply.*
   - ❌ *We don't have **time enough**.* → ✅ *We don't have **enough time**.*
3. **Bẫy 3 — Dùng `such a/an` với danh từ không đếm được hoặc danh từ số nhiều**:
   - ❌ *It was **such a** good news / **such a** reliable colleagues.*
   - ✅ *It was **such** good news / **such** reliable colleagues.*
4. **Bẫy 4 — Dùng `such` trước `many / much / few / little`**:
   - ❌ *There were **such many** applicants.*
   - ✅ *There were **so many** applicants.* *(Hoặc đổi thành `such a lot of applicants`)*.
5. **Bẫy 5 — Nhầm `so / such` với `very` hoặc `too`**:
   - ❌ *The task was **very** difficult **that** I gave up.* → ✅ *...**so** difficult **that**...*
   - ❌ *The task was **too** difficult **that** I gave up.* → ✅ *...**so** difficult **that**...* (hoặc *...**too** difficult **to** finish*).

## 5. Liên hệ tư duy Tiếng Việt (Vietnamese Contrastive Notes)

Người Việt học tiếng Anh rất dễ mắc 4 lỗi **"Vietlish"** kinh điển dưới đây do dịch từng chữ (word-by-word) từ tiếng Việt:

1. **Dùng chữ "quá" cho câu khen → Dùng nhầm `too` thay cho `very / so / really`**:
   - Tư duy Việt: *"Cảm ơn bạn nhiều quá!"* / *"Hôm nay trời đẹp quá!"*
   - Vietlish ❌: *Thank you **too** much!* / *Today is **too** beautiful!* (Nghe như phàn nàn "đẹp quá mức chịu đựng").
   - Chuẩn Anh ✅: *Thank you **so / very** much!* / *Today is **so / really** beautiful!*
2. **Chữ "đủ" luôn đứng trước trong tiếng Việt → Đặt `enough` trước tính từ**:
   - Tư duy Việt: *"đủ thông minh"* và *"đủ tiền"* đều đặt *"đủ"* đứng trước.
   - Vietlish ❌: *He is **enough smart**.*
   - Chuẩn Anh ✅: *He is **smart enough**.* (Tính/trạng từ đứng **trước** `enough`; chỉ danh từ mới đứng **sau** `enough`: *enough money*).
3. **Thói quen lặp lại "nó / chúng" cuối câu**:
   - Tư duy Việt: *"Bài toán này khó quá tôi không giải **nó** được."*
   - Vietlish ❌: *This math problem is too hard for me to solve **it**.*
   - Chuẩn Anh ✅: *This math problem is too hard for me to solve.* (Lưu ý: nếu dùng `so...that` thì BẮT BUỘC phải giữ `it`: *...so hard that I can't solve **it**.*).
4. **Dùng "quá ... nên không thể" thành `too ... so can't`**:
   - Tư duy Việt: *"Tôi mệt quá nên không đi được."*
   - Vietlish ❌: *I am **too tired so I can't** go.*
   - Chuẩn Anh ✅: *I am **too tired to** go.* hoặc *I am **so tired that** I can't go.*

## 6. Ứng dụng đời sống (Real-life Applications)

### Tình huống 1: Hội thoại giao tiếp hằng ngày (Tìm nhà thuê)
> **Mai:** Did you check out that studio near the station?
> **Nam:** Yeah, it's **affordable enough for a fresh graduate to rent**, and the **commute** to work would be short. However, the living room is **too small to invite** friends over, and there's **so much** street noise **that** I wouldn't be able to **concentrate** at night.
- **Giải thích:**
  - `affordable enough for ... to rent`: Đạt ngưỡng đủ khả năng chi trả.
  - `too small to invite`: Nhỏ vượt ngưỡng chịu đựng → không mời bạn được.
  - `so much ... that`: Nhấn mạnh lượng tiếng ồn không đếm được dẫn đến hệ quả mất tập trung.

### Tình huống 2: Email công việc (Xin gia hạn Deadline)
> *Dear Ms. Lan,*
> *I am writing regarding tomorrow's client presentation. We have received **such an overwhelming number of** last-minute data updates **that** our analysts do not have **enough time to verify** every figure accurately. The current **deadline** is **too tight for the team to guarantee** an error-free deck. Could we **postpone** the review by 24 hours?*
- **Giải thích:** Dùng `such an ... that` và `not ... enough time to` kết hợp `too tight ... to` giúp trình bày lý do **khách quan, chuyên nghiệp** mà không mang cảm giác đổ lỗi.

### Tình huống 3: Bài viết IELTS Writing Task 2 (Chủ đề Công nghệ & An ninh mạng)
> *Modern financial platforms have become **so sophisticated that** ordinary users often fail to recognize hidden security risks. **So vulnerable is** personal data in poorly regulated apps **that** a single breach can cause **such tremendous** financial **consequences that** victims take years to recover.*
- **Giải thích:** Sử dụng đan xen `so + adj + that`, **đảo ngữ `So + adj + be + S + that`** và `such + adj + N + that` giúp bài viết đạt **Lexical Resource & Grammatical Range** ở mức B2–C1.
